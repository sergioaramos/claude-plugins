# claude-plugins

Marketplace personal de plugins para [Claude Code](https://claude.com/claude-code).

```bash
claude plugin marketplace add sergioaramos/claude-plugins
claude plugin install sergio-dev@sergio-plugins
```

| Plugin | Qué es |
|---|---|
| [`sergio-dev`](plugins/sergio-dev/) | Flujo spec-driven en español (EARS + TDD), revisores con modelo económico y hooks de seguridad. |

Autor: Sergio Ramos ([@sergioaramos](https://github.com/sergioaramos)). MIT.
